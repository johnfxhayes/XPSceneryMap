XP Scenery Map is a tool that displays your custom airports on a global map.

I came up with this program for myself as someone who has a lot of freeware/payware scenery and wanted an easy way to come up with flight ideas from one custom scenery to another.

You can search and filter by airport/heliport/seaport.

Hovering over an icon displays the airport's code.

Clicking on an airport will display various information like field elevation, runways, location and where it is installed on your computer.

Scenery stored outside your custom scenery folder is included when that folder is connected with a shortcut, a symbolic link, or a junction.

Windows and Mac are both in this repository. Download [version 1.1](https://github.com/johnfxhayes/XPSceneryMap/releases/tag/1.1): `XPSceneryMap-1.1.zip` for Windows, and `XPSceneryMap-Mac-1.1.zip` for Mac.
